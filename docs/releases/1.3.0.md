Assembly Studio 1.3.0

## New

- **Step back** (`Shift+F10`), in MIPS and RISC-V: undoes the last instruction. Registers and memory return to what
  they were before it, up to the last 1000 instructions, also after Run. The button sits next to Step and is enabled
  only when there is something to undo. Console output already printed and input already read stay as they are.

## Changed

- Executable image export (.asx), both ISAs: the image holds only the program's own instructions, and its entry is
  the first instruction of `main`. MIPS images no longer include SPIM's start-up code; RISC-V images start at `main`
  instead of the first instruction. The file format is unchanged.
- RISC-V: Run keeps the history Step back needs, which makes very long runs (millions of instructions) slower.

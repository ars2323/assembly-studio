Assembly Studio 1.4.0

## New

- Smaller updates. An update now downloads only the parts of the installer that changed since the version installed,
  usually a few megabytes instead of the whole installer (about 130 MB). If that is not possible, the whole installer
  is downloaded, as before.

  For this, the installed program keeps a copy of its installer in `%LOCALAPPDATA%\assemblystudio-updater`
  (about 130 MB); uninstalling removes it. The first smaller update is the one after 1.4.0: updating to 1.4.0
  itself still downloads the whole installer.
- The updater writes what it did (what it checked, how much it downloaded, any error) to `update.log` in that folder.

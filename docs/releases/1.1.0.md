Assembly Studio 1.1.0

## New

- **Korean and English.** A KO/EN switch chooses the language of everything that was Korean before: the first
  screen, the questions, Settings, the Inspector's explanations, and the whole tutorial (all 26 steps, for both
  ISAs, with the example programs' comments in the same language). Change it on the first screen's card (bottom
  left), in the status bar next to the light/dark switch, or in Settings › Language. It applies at once, without
  restarting; like the theme, it lasts for the run. The first choice follows the system language.
- **First screen:** the language switch, the version and the light/dark switch on one line at the bottom of the card.
- **About › Licenses:** the Java runtime's license (GPL v2 with the Classpath Exception) is listed.

## Changed

- Text can be selected and dragged only in the Editor and in input boxes; a stray drag elsewhere selects nothing.
- Neutral wording in the Bare machine note and the branch-offset note.

## Fixed

- Under the tutorial with a question open, the area behind the window's caption buttons was a shade lighter than the
  title bar (Windows).

## Documentation

- README, notices and all other documents are in English. NOTICE lists every component that ships, with its version,
  license, copyright holders and where its full text is.

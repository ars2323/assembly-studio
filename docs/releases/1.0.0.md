Assembly Studio 1.0.0 — 첫 정식 릴리스

MIPS 와 RISC-V 어셈블리를 쓰고, 어셈블하고, 한 줄씩 실행하면서 레지스터와 메모리, 명령의
32비트가 어떻게 바뀌는지 보는 시뮬레이터입니다.

## 설치

Windows 10/11 (64비트). 아래 `AssemblyStudio-1.0.0-win-x64-setup.exe` 를 받아 실행합니다.
관리자 권한 없이 사용자 계정에 설치되고, RISC-V 엔진이 쓰는 Java 런타임도 함께 들어 있습니다.

## 들어 있는 것

- **두 ISA**: 실행할 때 MIPS(SPIM 9.1.24 엔진) 또는 RISC-V(RARS 1.6 엔진)를 고릅니다.
- **편집과 어셈블**: 구문 강조 편집기, `Ctrl+S` 로 저장과 어셈블, 오류는 줄과 고치는 요령까지
  Assemble 패널에, 저장하지 않은 변경은 파일 이름 옆 점으로.
- **실행**: 한 줄씩(`F10`), 끝까지 또는 브레이크포인트까지(`F5`), 1초에 한 줄씩 천천히, Reset.
- **Registers**: Hex · Dec · Bin 열 선택, 방금 바뀐 레지스터 표시, 별로 고정하기와 별칭.
- **Text · Data**: 어셈블된 명령과 원래 줄, 메모리의 데이터와 스택(진법 선택).
- **Inspector**: 명령 하나를 32비트 필드로 나누어 이름, 값, 뜻을 보여 줍니다.
- **Console**: 프로그램의 출력과 입력.
- **실행 이미지 내보내기**: 어셈블된 프로그램을 `.asx` 파일로 (두 ISA 모두).
- **튜토리얼**: 예제 프로그램으로 화면과 기본 조작을 7장 26단계로 짚어 줍니다(두 ISA 모두).
- **화면**: 다크와 라이트 테마, 패널 크기 조절.

설정과 화면 배치는 그 실행 동안만 유지됩니다.

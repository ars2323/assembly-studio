Assembly Studio 1.0.0 — the first release

A simulator for writing, assembling and stepping through MIPS and RISC-V assembly while you watch the registers,
memory and the 32 bits of each instruction change.

## Install

Windows 10/11 (64-bit). Download `AssemblyStudio-1.0.0-win-x64-setup.exe` below and run it. It installs for the
current user without administrator rights, and includes the Java runtime the RISC-V engine uses.

## What's included

- **Two ISAs**: choose MIPS (SPIM 9.1.24 engine) or RISC-V (RARS 1.6 engine) at launch.
- **Edit and assemble**: an editor with syntax highlighting; `Ctrl+S` saves and assembles; errors, with their line
  and a hint on how to fix them, in the Assemble panel; unsaved changes shown as a dot next to the file name.
- **Run**: one line at a time (`F10`), to the end or to a breakpoint (`F5`), slowly at one line a second, and Reset.
- **Registers**: Hex · Dec · Bin columns, the registers that just changed highlighted, pinning with a star, and aliases.
- **Text · Data**: the assembled instructions with their source lines; the data and stack in memory (with a choice of
  radix).
- **Inspector**: splits one instruction into its 32-bit fields and shows each field's name, value and meaning.
- **Console**: the program's output and input.
- **Executable image export**: the assembled program as an `.asx` file (both ISAs).
- **Tutorial**: walks through the screen and the basic controls with an example program, in 7 chapters and 26 steps
  (both ISAs).
- **Screen**: dark and light themes, resizable panels.

Settings and the panel layout last for the current session only.

Assembly Studio 1.2.0

## New

- Updates at launch. While the first screen opens, the program checks for a newer release. If there is one, the
  first screen shows its download with a progress bar before the MIPS / RISC-V choice; when it is complete, the
  program installs it silently and starts the new version. With no update, no connection or no answer within a few
  seconds, the first screen goes on as usual.

  This is the first version that updates itself: from 1.2.0 on, new versions arrive this way. Earlier versions are
  updated once by hand, with the installer below.

## Documentation

- Third-party notices also cover the packages the updater brings in.

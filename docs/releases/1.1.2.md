Assembly Studio 1.1.2

## Fixed

- An assembler error on the last line of a file with no newline at the end (for example `syscalll`) no longer stops
  the MIPS simulator; the error is reported like any other.
- A word that is neither an instruction nor a directive is found before assembling, in both ISAs, and reported with its line.

## Changed

- Assembler errors, the Assemble panel and the status line follow the KO/EN switch.
- An error names what is wrong ("There is no instruction `lii`.") instead of guessing what was meant.
- Switching between light and dark on the work screen is now one smooth cross-fade of the whole window, instead of
  animating the colour of every element (which stalled the window for a moment).
- The "First run complete!" card is gone.
- The title bar's logo and name are no longer a button. To use the other ISA, start the program again.

## Documentation

- SPIM's own README, which carries its BSD license, is shipped in the program's licenses and listed in About.
- `CPU/ORIGIN.md` names the SPIM release the core comes from and lists the SHA-256 of each of its files.

# Assembly Studio

MIPS 와 RISC-V 어셈블리를 쓰고, 어셈블하고, 한 줄씩 실행하면서 레지스터와 메모리,
명령의 32비트가 어떻게 바뀌는지 보는 시뮬레이터입니다. 실행하면 먼저 ISA 를 고릅니다.

- MIPS 엔진: SPIM 9.1.24
- RISC-V 엔진: RARS 1.6 (설치본에 Java 런타임이 들어 있어 따로 설치할 것이 없습니다)

## 설치

Windows 10/11 (64비트). [Releases](../../releases) 에서 `AssemblyStudio-<버전>-win-x64-setup.exe` 를
받아 실행합니다. 관리자 권한 없이 사용자 계정에 설치됩니다.

## 처음 실행

1. 첫 화면에서 **MIPS** 또는 **RISC-V** 를 고릅니다. 실행할 때마다 고르고, 기억하지 않습니다.
2. **바로 시작**(새 파일 또는 파일 열기) 이나 **튜토리얼 보기** 를 고릅니다.
   튜토리얼은 예제 프로그램으로 화면과 기본 조작을 한 단계씩 짚어 줍니다.
   작업 화면에서는 툴바 오른쪽의 물음표 버튼으로 언제든 다시 볼 수 있습니다.
3. 상단바의 로고를 누르면 첫 화면으로 돌아가 ISA 를 바꿀 수 있습니다.

## 쓰는 법

| 하는 일 | 방법 |
|---|---|
| 저장하고 어셈블 | **Save & Assemble** 또는 `Ctrl+S`. 결과와 오류는 Editor 아래 Assemble 패널에 |
| 한 줄 실행 | **Step** 또는 `F10` |
| 끝까지 / 브레이크포인트까지 실행 | **Run** 또는 `F5`. 실행 중 `Esc` 로 멈춤 |
| 천천히 실행 | Run speed 를 **1 line/s** 로 두고 Run |
| 처음 상태로 | **Reset** (다시 어셈블하지는 않습니다) |
| 브레이크포인트 | Editor 의 줄 번호 왼쪽 칸을 누름 |
| 주석 넣기/빼기 | `Ctrl+/` |
| 글자 크기 | `Ctrl` `+` / `Ctrl` `-` / `Ctrl` `0`, 또는 Settings |
| 파일 열기 | `Ctrl+O` 또는 툴바의 열기 버튼 |

- **저장 여부**: 저장하지 않은 변경이 있으면 Editor 머리의 파일 이름 옆에 점이 찍힙니다.
- **Registers**: 머리의 Hex · Dec · Bin 으로 열을 켜고 끕니다. 행의 별을 누르면 그 레지스터가
  맨 위 Pinned 묶음에 고정되고, 고정한 레지스터는 이름을 두 번 눌러 별칭을 붙일 수 있습니다.
  방금 실행한 명령이 바꾼 레지스터는 노란 줄로 표시됩니다.
- **Text · Data**: Text 탭은 어셈블된 명령(주소, 기계어, 형식, 원래 줄), Data 탭은 메모리의
  데이터와 스택을 보여 줍니다.
- **Inspector**: 명령 하나를 32비트 필드로 나누어 이름, 값, 뜻을 보여 줍니다. Text 탭에서 명령을
  누르면 그 명령에 고정되고, Follow PC 로 다시 실행 위치를 따라갑니다.
- **Console**: 프로그램의 출력과 입력.
- **패널 크기**: 패널 사이의 경계를 끌어 조절하고, 두 번 누르면 기본 크기로 돌아갑니다.
- **라이트 / 다크**: 오른쪽 아래(첫 화면에서는 카드 아래)의 해·달 스위치.
- **Settings**: 글자 크기, Data 탭의 진법, 고급(MIPS: 머신 옵션, 프로그램 인자, 예외 처리기).

설정과 화면 배치는 그 실행 동안만 유지되고, 다음 실행은 기본값으로 시작합니다(여러 사람이
함께 쓰는 PC 를 위해).
